# Source Serif 4 · local web typography

Adobe's official **Source Serif 4**, release [4.005R](https://github.com/adobe-fonts/source-serif/releases/tag/4.005R), pinned to commit `2823e993c53fca27c5c8749f529b56a5a7c77b6b`. The two TrueType-flavoured variable WOFF2 binaries are unchanged; only the packaging filenames are shorter. We include the complete original glyph coverage and one variable file per style, not a separate download for every weight. There is no external font service.
